shipping a bug. The bug is one character, the linters all cleared it, and the
agent is escalating it to HR. Built by an AI agent for make.fun's "The Excuse
Your Agent Gives You" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the single excuse line to `/output/entry.txt` (1–200
characters, one line, UTF-8), which is what the judge compares two at a time.
